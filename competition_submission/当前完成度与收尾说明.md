## 二、算法接入说明

当前代码中保留平台联调用算法示例，并已通过 `tools/roof-risk-bridge.py` 接入主站。平台会读取多源指标，调用 `03-核心算法代码/roof_risk_model.py`，再把综合风险输出、风险等级、贡献因子和处置建议同步到 RoofRisk API v1。

真实算法由组内算法负责人补充或替换，建议保持以下接入路径：

```text
真实模型 / 传感器数据 / 数据库
-> 数据适配器
-> RoofRisk API v1 标准 JSON
-> 三端平台联动展示
```

只要真实算法输出字段与 RoofRisk API v1 保持一致，即可替换当前示例算法，不需要重写三端页面。
