- 两份 Word 报告、运行说明、审查指南和演示脚本。

## 二、数据与模型口径

当前运行包使用老师真实 CSV 的构建期推理结果，展示多源指标、综合风险、风险等级、四级概率、特征证据和处置建议。

```text
老师真实 CSV
-> 校验、切段、卡尔曼平滑与标准化
-> XGBoost 构建期推理
-> RoofRisk API v1 标准 JSON
-> 企业端 / 监管端 / 智库端 / 只读端
```

生产实时传感器或在线模型可通过数据适配器输出相同字段，不需要重写角色页面。

## 三、云端与权限口径

```text
浏览器 -> Vercel 静态前端 -> Render Node API -> Supabase Auth / RBAC / 审计
```

- Vercel 承载页面、Three.js、ECharts 和静态资源。
- Render 承载会话、权限校验和 RoofRisk 业务接口。
- Supabase 持久化账户、角色、权限、账号状态和审计日志。
- 生产密钥只保存在 Render 环境变量，不进入浏览器、GitHub 或提交包。
