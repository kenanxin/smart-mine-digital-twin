## 二、算法预留说明

当前运行包使用老师真实 CSV 的构建期推理结果，用于说明多源指标输入、综合风险输出、风险等级、特征证据和处置建议。

生产实时算法或传感器服务可按以下路径替换，建议保持以下接入路径：

```text
真实模型 / 传感器数据 / 数据库
-> 数据适配器
-> RoofRisk API v1 标准 JSON
-> 三端平台联动展示
```

只要真实算法输出字段与 RoofRisk API v1 保持一致，即可替换当前模拟数据源，不需要重写三端页面。
