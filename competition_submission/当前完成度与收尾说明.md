## 二、算法接入说明

当前代码已向算法组成果靠齐，并通过 `tools/roof-risk-bridge.py` 接入主站。平台会读取算法组 8 维输入特征，调用 `03-核心算法代码/roof_risk_model.py`，再把 XGBoost 四级风险概率、预测类别、红黄橙蓝预警等级、综合展示分值、处置建议和 Agent 预警闭环摘要同步到 RoofRisk API v1。

算法组原始成果包括 `D:\矿业\揭榜挂帅\揭榜挂帅` 中的 XGBoost / RandomForest / MOA-Transformer 模型评估结果，以及 `D:\矿业\agent 代码(1)\agent 代码` 中的六 Agent 工作流。主站当前采用算法组标注的最佳模型 `xgboost` 作为展示和接口口径。

后续如算法负责人提供更完整的模型服务，只需保持以下接入路径：

```text
算法组模型服务 / 传感器数据 / 数据库
-> 数据适配器
-> RoofRisk API v1 标准 JSON
-> 三端平台联动展示
```

只要算法输出字段与 RoofRisk API v1 保持一致，即可替换当前适配器，不需要重写三端页面。
