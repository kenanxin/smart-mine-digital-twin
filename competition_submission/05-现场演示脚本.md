# 五分钟现场演示脚本

## 录制前

1. 打开后端健康检查，确认返回正常。
2. 准备企业、监管、智库、只读和超级管理员五类账户，密码只放在私密账户卡。
3. 浏览器缩放保持 100%，关闭无关通知，提前完成一次完整彩排。

## 00:00-00:40 项目与真实数据

讲解：“本系统面向煤矿顶板灾变预警，接入老师提供的 20,000 行真实监测数据，经卡尔曼平滑和 XGBoost 推理，通过统一的 RoofRisk API v1 驱动多角色页面。”

操作：登录企业端，指出页面中的真实记录编号、风险分值和主要特征证据。

## 00:40-02:10 企业端数字孪生

操作：依次切换应力场、位移场和综合风险场，再播放顶板灾变全过程演示。

讲解：“风险场将监测点插值映射到井下空间；六阶段演示从正常监测推进到停机、撤人、封控和补强支护。”

## 02:10-03:00 监管端闭环

操作：退出后登录监管端，选择风险事件，展示督办、闭环推进和归档能力。

讲解：“监管端与企业端读取同一个事件状态，但权限不同；归档只能由监管角色执行。”

## 03:00-03:50 智库端与只读端

操作：登录智库端，展示四级概率、真实标签、预测标签、置信度和特征证据；随后登录只读端，指出没有写操作。

讲解：“只读端复用智库端布局，但仍保持独立 viewer 角色，后端不会授予写权限。”

## 03:50-04:35 超级管理员

操作：进入管理中心，展示用户列表、角色选项和审计日志。不要在录屏中输入或显示真实密码。

讲解：“超级管理员可创建账户并分配企业、监管、智库或只读角色；系统禁止当前管理员停用或降级自身。”

## 04:35-05:00 部署与总结

讲解：“前端部署在 Vercel，Node 后端部署在 Render，Supabase 持久化用户、RBAC 权限和审计；Service Role Key 仅保存在后端。系统同时保留同源码本地启动方案，保证现场网络异常时仍可演示。”

## 禁止表述

- 不说“当前都是模拟数据”。应说明真实 CSV 和 XGBoost 已接入，六阶段过程属于可复现演示模式。
- 不说“数据库以后再接”。应说明 Supabase 已用于身份、角色、权限和审计持久化。
- 不展示生产密码、API Key、令牌或 Supabase Service Role Key。
