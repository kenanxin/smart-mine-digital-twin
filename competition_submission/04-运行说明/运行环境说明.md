# 运行环境说明

## 1. 项目与生产地址

- 项目目录：`D:\矿业\smart-mine-v2-balanced`
- 生产登录页：`https://smart-mine-v2-balanced.vercel.app/login`
- 后端健康检查：`https://smart-mine-v2-balanced.onrender.com/healthz`
- GitHub：`https://github.com/kenanxin/smart-mine-digital-twin`

生产演示优先使用 Vercel 地址，不需要自定义域名。

## 2. 运行环境

- Node.js：18 或以上版本。
- 浏览器：最新版 Chrome 或 Edge，建议启用硬件加速。
- Python：仅在重新构建真实数据或运行算法示例时需要，平台日常运行不依赖 Python。

## 3. 本地离线兜底

```powershell
cd D:\矿业\smart-mine-v2-balanced
$env:PORT="8092"
npm start
```

浏览器打开 `http://localhost:8092/login`。未登录访问其他页面会自动进入登录页。

Render 免费实例首次访问可能需要冷启动。若生产登录显示认证服务暂不可用，先访问健康检查，等待恢复后再登录。Render 重启后 Web 会话失效，重新登录即可；Supabase 中的账户和角色不会丢失。

## 4. 角色账号与权限

生产账户由超级管理员在管理中心创建并通过 Supabase 持久化。演示账号与密码使用现场私密账户卡，不写入源码、公开文档或提交包。

| 角色 | 自动进入 | 主要权限 |
|---|---|---|
| 企业端 | 企业端门户 | 查看、选择事件、推进处置、重置闭环 |
| 监管端 | 监管端门户 | 查看、选择事件、推进督办、归档事件 |
| 智库端 | 智库端门户 | 查看模型解释与事件复盘，无写操作 |
| 只读端 | 智库端布局 | 只读查看，无写操作 |
| 超级管理员 | `/admin` | 创建账户、分配角色、停用账户、重置密码、查看审计 |

角色由后端会话决定，修改 URL 中的 `portal` 参数不能越权。前端控制可见操作，Render 后端再次执行权限校验。

## 7. RoofRisk API v1

生产环境通过 Vercel 的 `/api/*` 代理访问 Render，本地环境直接访问 Node 服务：

```text
GET  /api/roof-risk/current
GET  /api/roof-risk/history
GET  /api/roof-risk/explain
POST /api/roof-risk/evaluate
GET  /api/roof-risk/events
POST /api/roof-risk/select
POST /api/roof-risk/closed-loop/advance
```

认证接口：

```text
POST /api/auth/login
GET  /api/auth/session
POST /api/auth/logout
```

接口字段见 `docs/api/roof-risk-api-v1.md`。除 `/healthz` 和登录接口外，业务接口要求有效会话。

当前提交包包含老师真实 CSV 的数据处理与 XGBoost 推理说明。在线模型或实时传感器服务可在保持 RoofRisk API v1 字段一致的前提下替换构建期数据源。

## 9. 云端架构与数据持久化

```text
浏览器 -> Vercel 静态前端 -> /api 代理 -> Render Node 服务
                                      -> Supabase Auth / PostgreSQL RBAC 与审计
                                      -> 真实 CSV / XGBoost 构建产物
```

- Vercel：托管登录页、管理页、业务页面和三维静态资源。
- Render：提供认证会话、权限校验和 RoofRisk API v1。
- Supabase：持久化用户、角色、权限、账号状态和审计日志。
- 安全边界：`SUPABASE_SERVICE_ROLE_KEY` 仅存在于 Render 环境变量中，不进入前端和提交包。
