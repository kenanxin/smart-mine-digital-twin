# 运行环境说明

## 1. 项目目录

```text
D:\矿业\smart-mine-v2-balanced
```

## 2. 运行环境

- Node.js：建议 18 或以上版本。
- 浏览器：建议 Chrome 或 Edge。
- Python：仅用于运行 `03-核心算法代码` 中的算法示例，平台主体不依赖 Python。

## 3. 启动三维平台

```powershell
cd D:\矿业\smart-mine-v2-balanced
$env:PORT="8092"
node server.js
```

浏览器打开：

```text
http://localhost:8092/
```

未登录访问会自动进入统一登录页。登录成功后，系统根据账号角色自动进入对应门户：

```text
http://localhost:8092/login
```

## 4. 三端账号与权限

| 账号 | 密码 | 登录后门户 |
|---|---|---|
| `enterprise_operator` | `Mine@2026` | 企业端 |
| `regulator_officer` | `Safe@2026` | 监管端 |
| `expert_analyst` | `Model@2026` | 智库端 |

三端共享同一 RoofRisk 事件状态。角色由后端会话决定，修改 URL 中的 `portal` 参数不能切换门户。企业端允许推进/重置，监管端允许推进/归档，智库端只读。

## 5. 风险场参数

| 场类型 | URL 参数 |
|---|---|
| 顶板应力场 | `field=stress` |
| 顶板位移场 | `field=displacement` |
| 综合风险场 | `field=risk` |

示例：

```text
http://localhost:8092/?scene=v2&view=underground&field=stress&portal=enterprise
http://localhost:8092/?scene=v2&view=underground&field=displacement&portal=enterprise
http://localhost:8092/?scene=v2&view=underground&field=risk&portal=enterprise
```

## 6. 顶板灾变六阶段演示

企业端页面中可播放顶板灾变六阶段全过程：

```text
正常监测 -> 应力集中 -> 离层扩展 -> 支护异常 -> 垮落预警 -> 应急处置
```

六阶段演示使用独立演示事件，避免与当前监管端事件状态混用。

## 9. 建议演示流程

1. 打开企业端默认综合风险场。
2. 切换应力场、位移场、综合风险场。
3. 播放顶板灾变六阶段全过程。
4. 退出登录后使用监管账号，展示区域风险态势、事件选择、监管督办和闭环归档。
5. 退出登录后使用智库账号，展示模型输入、指标贡献、判别依据和只读权限。
6. 展示 RoofRisk API v1 文档、真实数据血缘和算法替换边界。
