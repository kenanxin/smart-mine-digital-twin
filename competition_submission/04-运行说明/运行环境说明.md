# 运行环境说明

## 1. 项目目录

```text
D:\矿业\smart-mine-publish
```

## 2. 运行环境

- Node.js：建议 18 或以上版本。
- 浏览器：建议 Chrome 或 Edge。
- Python：用于 `tools/roof-risk-bridge.py` 调用 `03-核心算法代码/roof_risk_model.py`，将算法结果接入 RoofRisk API v1。
- 线上部署：Render Web Service，Node.js 运行时，启动命令为 `npm start`。

线上访问地址：

```text
https://smart-mine-v2-balanced.onrender.com/
```

说明：Render 免费实例长时间无人访问后会休眠，首次打开可能需要等待约 50 秒或更久。若页面显示旧数据，可在 URL 后追加 `rev=20260901-final` 强制刷新浏览器缓存。

## 3. 启动三维平台

```powershell
cd D:\矿业\smart-mine-publish
$env:PORT="8092"
node server.js
```

浏览器打开：

```text
http://localhost:8092/
```

三维主展示入口：

```text
http://localhost:8092/?scene=v2&view=underground&field=risk
```

## 4. 三端入口

三端入口用于展示业务端差异化工作台。企业端保留三维主画布和现场处置卡片；监管端、智库端是区域督办和模型解释专题面板，不作为三维主画布入口。录制三维数字孪生画面时使用“不带 `portal` 参数”的主展示入口。

三维主展示：

| 页面 | URL |
|---|---|
| 线上主三维 | `https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&rev=20260901-final` |
| 本地主三维 | `http://localhost:8092/?scene=v2&view=underground&field=risk` |

线上入口：

| 页面 | URL |
|---|---|
| 企业端 | `https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&portal=enterprise&rev=20260901-final` |
| 监管端 | `https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&portal=regulator&rev=20260901-final` |
| 智库端 | `https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&portal=expert&rev=20260901-final` |

本地入口：

| 页面 | URL |
|---|---|
| 企业端 | `http://localhost:8092/?scene=v2&view=underground&field=risk&portal=enterprise` |
| 监管端 | `http://localhost:8092/?scene=v2&view=underground&field=risk&portal=regulator` |
| 智库端 | `http://localhost:8092/?scene=v2&view=underground&field=risk&portal=expert` |

三端共享同一 RoofRisk 事件状态。监管端切换事件或推进闭环后，企业端和智库端会读取同一事件数据。

## 5. 风险场参数

| 场类型 | URL 参数 |
|---|---|
| 顶板应力场 | `field=stress` |
| 顶板位移场 | `field=displacement` |
| 综合风险场 | `field=risk` |

示例：

```text
http://localhost:8092/?scene=v2&view=underground&field=stress
http://localhost:8092/?scene=v2&view=underground&field=displacement
http://localhost:8092/?scene=v2&view=underground&field=risk
```

## 6. 顶板灾变六阶段演示

企业端页面中可播放顶板灾变六阶段全过程：

```text
正常监测 -> 应力集中 -> 离层扩展 -> 支护异常 -> 垮落预警 -> 应急处置
```

六阶段演示使用独立演示事件，避免与当前监管端事件状态混用。

## 8. 算法示例

目录：

```text
D:\矿业\smart-mine-publish\competition_submission\03-核心算法代码
```

运行方式：

```powershell
cd D:\矿业\smart-mine-publish\competition_submission\03-核心算法代码
python roof_risk_model.py
```

当前主站启动后会通过 `tools/roof-risk-bridge.py` 调用该算法文件，并把算法组 XGBoost 四级风险概率、预测类别、预警等级、综合展示分值、Agent 闭环摘要和处置建议写入 `/api/roof-risk/current`、`/api/roof-risk/explain` 和三端页面。后续算法负责人提供完整模型服务时，只需保持 RoofRisk API v1 输入输出字段一致。

## 9. 建议演示流程

1. 打开企业端默认综合风险场。
2. 切换应力场、位移场、综合风险场。
3. 播放顶板灾变六阶段全过程。
4. 切换监管端，展示区域风险态势、事件选择、监管督办和闭环归档。
5. 切换智库端，展示模型输入、指标贡献、判别依据和接口状态。
6. 展示 RoofRisk API v1 文档、“算法组 XGBoost 四级预警模型”和 Agent 闭环状态。
