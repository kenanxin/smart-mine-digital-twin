# 演示视频录制说明

## 1. 建议文件名

```text
05-平台主要功能演示.mp4
```

## 2. 建议时长

2-4 分钟。

## 3. 录制前检查

- 确认线上平台地址可打开：`https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&portal=enterprise&rev=f81d039`
- 如使用本地演示，确认本地地址可打开：`http://localhost:8092/`
- 确认默认进入企业端井下综合风险场。
- 确认 Three.js 三维场景正常显示。
- 确认中央综合风险指数、右侧顶板风险态势、智能决策建议均显示 `89.26`。
- 确认三端切换正常。
- 确认监管端显示 6 座矿井在线，第一条事件为 `红色预警 · 89.26`。
- 确认监管端闭环推进后页面有状态变化。
- 确认智库端模型解释和接口状态正常显示，模型服务接口显示 `接口在线 · 算法已接入`。
- 确认六阶段演示不卡死、无明显穿模、无乱码粗线条。

## 4. 建议录制顺序

1. 企业端：展示三维数字孪生和综合风险场。
2. 企业端：切换应力场、位移场、综合风险场。
3. 企业端：播放顶板灾变六阶段全过程。
4. 监管端：展示区域风险态势、事件队列、监管指令和闭环处置。
5. 智库端：展示模型输入、指标贡献、判别依据、接口状态和事件复盘。
6. 简要说明：真实算法已预留 RoofRisk API v1 标准接口，算法负责人可替换当前联调示例。

详细逐步操作可参考同目录：

```text
05-录屏操作路线稿.md
```
