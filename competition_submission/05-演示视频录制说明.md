# 演示视频录制说明

## 1. 建议文件名与时长

```text
05-平台主要功能演示.mp4
```

建议时长 3-5 分钟，分辨率 1920x1080，浏览器缩放 100%。

## 2. 录制前检查

- 打开生产登录页：`https://smart-mine-v2-balanced.vercel.app/login`。
- 打开健康检查：`https://smart-mine-v2-balanced.onrender.com/healthz`。
- 确认企业、监管、智库、只读和超级管理员账户可登录。
- 确认 Three.js、三张 ECharts 图表和真实记录信息正常显示。
- 确认六阶段演示可完成，监管端可归档，智库端与只读端无写操作。
- 确认录屏区域不会显示密码、密钥、令牌或浏览器密码管理器。

## 3. 建议录制顺序

1. 企业端：真实记录、数字孪生和综合风险场。
2. 企业端：应力场、位移场、综合风险场切换及六阶段过程。
3. 监管端：区域态势、事件队列、监管督办和归档。
4. 智库端：模型输入、四级概率、特征证据和事件复盘。
5. 只读端：展示相同信息布局但没有写操作。
6. 超级管理员：展示账户、角色与审计，不输入或显示真实密码。
7. 总结 Vercel + Render + Supabase 架构与 RoofRisk API v1。

## 4. 推荐口径

```text
本平台通过 RoofRisk API v1 统一接入顶板离层、支护、涌水、微震等多源数据，并将老师提供的 20,000 行真实 CSV 经卡尔曼预处理和 XGBoost 构建期推理后同步到各角色页面。六阶段灾变过程是独立、可复现的演示模式；生产环境可按相同字段合同替换为实时传感器或在线模型服务。账户、角色、权限和审计由 Supabase 持久化，Render 后端执行权限校验，Vercel 提供前端访问入口。
```

## 5. 网络异常兜底

在项目目录运行：

```powershell
$env:PORT="8092"
npm start
```

然后打开 `http://localhost:8092/login`。本地兜底使用同一份源码，不是另一套演示页面。
