# 演示视频录制说明

## 1. 建议文件名

```text
05-平台主要功能演示.mp4
```

## 2. 建议时长

2-4 分钟。

## 3. 录制前检查

- 确认平台地址可打开：`http://localhost:8092/`
- 确认未登录先进入统一登录页，企业账号登录后自动进入企业端。
- 确认 Three.js 三维场景正常显示。
- 确认退出后使用监管账号和智库账号，系统分别自动进入对应门户。
- 确认监管端闭环推进后页面有状态变化。
- 确认智库端模型解释和接口状态正常显示。
- 确认六阶段演示不卡死、无明显穿模、无乱码粗线条。

## 4. 建议录制顺序

1. 企业端：展示三维数字孪生和综合风险场。
2. 企业端：切换应力场、位移场、综合风险场。
3. 企业端：播放顶板灾变六阶段全过程。
4. 监管端：展示区域风险态势、事件队列、监管指令和闭环处置。
5. 智库端：展示模型输入、指标贡献、判别依据、接口状态和事件复盘。
6. 简要说明：真实算法已预留 RoofRisk API v1 标准接口，算法负责人可替换当前联调示例。

## 5. 录制口径

建议表述：

```text
本平台通过 RoofRisk API v1 统一接入顶板应力、位移、支护、微震等多源数据，并将老师提供的真实 CSV 经卡尔曼预处理和 XGBoost 构建期推理结果同步到企业端、监管端和智库端。六阶段灾变过程是独立的可复现演示模式；生产环境可按相同字段契约替换为实时传感器或模型服务。
```
