# 演示视频录制说明

## 1. 建议文件名

```text
05-平台主要功能演示.mp4
```

## 2. 建议时长

2-4 分钟。

## 3. 录制前检查

- 确认平台地址可打开：`http://localhost:8092/`
- 确认默认进入企业端井下综合风险场。
- 确认 Three.js 三维场景正常显示。
- 确认三端切换正常。
- 确认监管端闭环推进后页面有状态变化。
- 确认智库端模型解释和接口状态正常显示。
- 确认六阶段演示不卡死、无明显穿模、无乱码粗线条。

## 4. 建议录制顺序

1. 企业端：展示三维数字孪生和综合风险场。
2. 企业端：切换应力场、位移场、综合风险场。
3. 企业端：播放顶板灾变六阶段全过程。
4. 监管端：展示区域风险态势、事件队列、监管指令和闭环处置。
5. 智库端：展示模型输入、指标贡献、判别依据、接口状态和事件复盘。
6. 简要说明：真实算法已预留 RoofRisk API v1 标准接口，算法负责人可替换当前联调示例。

## 5. 录制口径

建议表述：

```text
本平台通过 RoofRisk API v1 统一接入顶板应力、位移、支护、微震等多源数据，并将模型输出同步到企业端、监管端和智库端。当前演示采用标准化模拟数据，真实算法和真实传感器数据可按相同字段合同替换接入。
```
