# 录屏操作路线稿

## 1. 录屏前准备

建议先打开线上企业端入口，等待三维场景、风险分值和右侧面板全部稳定后再开始录屏。

```text
https://smart-mine-v2-balanced.onrender.com/?scene=v2&view=underground&field=risk&portal=enterprise&rev=20260901-final
```

录屏前确认：

- 中央三维画面已出现井下巷道和设备，不停留在加载提示。
- 中央综合风险指数为 `89.26`。
- 右侧顶板风险态势和智能决策建议同样显示 `89.26`。
- 顶部三端按钮可以切换企业端、监管端、智库端。

## 2. 建议录屏时长

建议控制在 3 分钟左右。若比赛要求不限时，可放宽到 4 分钟，但不要超过主要功能展示范围。

## 3. 录屏路线

### 0:00-0:20 打开平台总览

操作：

1. 打开企业端线上入口。
2. 停留 5-8 秒，让画面显示平台标题、井下三维场景、综合风险指数。

画面重点：

- 平台名称：煤矿顶板灾变智能预警与可视化决策系统。
- 三维数字孪生场景。
- 顶板垮落预警、红色预警、综合风险指数 `89.26`。

可说：

```text
这是煤矿顶板灾变智能预警与可视化决策系统，平台以数字孪生场景为主视图，统一展示顶板压力、离层量、支架阻力、微震能量等多源监测数据。
```

### 0:20-0:50 展示风险场切换

操作：

1. 点击“应力场”。
2. 停留 3-5 秒。
3. 点击“位移场”。
4. 停留 3-5 秒。
5. 点击“综合风险场”。

画面重点：

- 风险场图例为低、中、高。
- 风险场与顶板灾变核心监测指标联动。
- 综合风险分值保持和右侧面板一致。

可说：

```text
平台支持应力场、位移场和综合风险场切换，用于表达不同监测指标在工作面和巷道中的空间分布，综合风险场用于最终预警研判。
```

### 0:50-1:30 播放顶板灾变全过程

操作：

1. 点击“顶板灾变全过程演示”。
2. 等六阶段自动推进，或按阶段按钮依次点击。
3. 每个阶段停留 3-5 秒。

画面重点：

- 正常监测。
- 顶板压力升高。
- 离层异常。
- 支架阻力异常。
- 顶板垮落预警。
- 应急处置演示。

可说：

```text
灾变全过程演示按照正常监测、应力集中、离层扩展、支护异常、垮落预警和应急处置六个阶段推进，展示风险从局部异常到红色预警再到处置闭环的变化过程。
```

### 1:30-2:10 展示监管端

操作：

1. 点击顶部“监管端”。
2. 展示区域矿井风险总览。
3. 展示预警事件队列。
4. 点击“监管复核通过”。
5. 观察闭环进度和当前环节变化。
6. 如状态已稳定，可再点击“直接闭环归档”展示最终闭环。

画面重点：

- 区域矿井风险总览显示 6 座矿井在线。
- 第一条事件为红色预警，风险分 `89.26`。
- 监管督办、企业反馈、专家意见形成闭环链路。

可说：

```text
监管端面向区域安全监管，汇聚多矿井预警事件，并对企业端处置过程进行复核督办。监管动作会推动三端共享的闭环状态变化。
```

### 2:10-2:45 展示智库端

操作：

1. 点击顶部“智库端”。
2. 展示多源输入。
3. 展示融合权重和判别依据。
4. 展示模型服务接口区域。

画面重点：

- 模型置信度。
- 多源输入：顶板压力、离层量、支架阻力、微震能量。
- 贡献因子。
- `接口在线 · 算法已接入`。
- 算法来源：本地算法桥接。

可说：

```text
智库端用于展示模型研判依据、指标贡献和事件复盘。当前平台通过 RoofRisk API v1 接入本地算法桥接结果，后续真实算法可按同一接口协议替换接入。
```

### 2:45-3:00 收尾

操作：

1. 停留在智库端接口区域或返回企业端综合风险场。
2. 不再快速切换页面，让最后画面稳定。

可说：

```text
整体平台完成了多源数据接入、顶板风险智能预警、三维可视化表达、企业监管智库三端协同和闭环处置展示，满足比赛原型演示和后续算法替换接入要求。
```

## 4. 不建议录入的内容

- 不展示 GitHub Token、Render 后台、PowerShell 凭证输入画面。
- 不在录屏中等待 Render 冷启动。
- 不录入长时间灰色加载画面。
- 不反复切换过多视角，避免观众看不清重点。
- 不强调“模拟数据很假”，统一表述为“标准化模拟多源数据，真实数据可按同一接口接入”。

## 5. 录屏后检查

录完后回看一次：

- 开头 10 秒内是否已经出现平台主界面。
- 三维画面是否可见。
- 是否至少展示了企业端、监管端、智库端。
- 是否出现 `89.26`、`6 座矿井在线`、`接口在线 · 算法已接入`。
- 是否没有录入 Token、账号密码、Render 后台等敏感画面。
