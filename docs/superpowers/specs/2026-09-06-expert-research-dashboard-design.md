# 智库端科研分析大屏设计

## 目标

在现有智库端增加“煤矿顶板灾变智库端风险机理分析平台”，用老师 CSV 的真实样本和当前记录展示风险分布、指标贡献、风险机理关联、历史趋势与专家解释，并提供一键生成专家建议能力。

## 范围

- 只改造 `expert` 门户，不改变企业端、监管端和单巷道 Three.js 场景。
- 使用现有 ECharts 6 集成，不新增图表框架。
- 图表只使用 `data/roof-risk-dataset.json` 及其来源的教师 CSV 统计结果；不存在统计依据时显示空状态。
- DeepSeek 为可选增强：服务端配置 `DEEPSEEK_API_KEY` 后调用，未配置或调用失败时使用本地规则解释。

## 页面结构

采用参考图的深色科研驾驶舱布局：固定左侧研究导航，顶部标题和数据状态，主区使用密集多宫格图表，下方放解释与建议工作区。

1. 顶部状态栏：平台标题、当前记录、数据时间、模型版本、解释来源。
2. 指标摘要：综合风险等级、模型置信度、异常指标数、样本覆盖率、当前事件状态。
3. 图表矩阵：风险等级环图、指标贡献横向柱状图、风险机理热力图、标准化偏离小提琴图、风险趋势折线图、样本分群散点图。
4. 解释区：数据证据、模型判别、风险机理、研究结论四个层级。
5. 专家建议区：生成按钮、来源标识、建议等级、建议内容、依据指标、建议时效和复制操作。

## 数据与 API

- 新增服务端 `POST /api/roof-risk/expert-advice`，请求包含当前记录和分析摘要。
- 服务端先验证会话与请求大小，再根据 `DEEPSEEK_API_KEY` 是否存在选择 DeepSeek 或本地解释器。
- DeepSeek 请求使用服务端密钥，前端不得读取或保存密钥；超时、非 2xx、无效 JSON 均回退本地解释。
- 返回统一结构：`source`, `generatedAt`, `riskLevel`, `summary`, `recommendations`, `evidence`, `timeHorizon`。
- 本地解释基于当前模型输出、P05-P95 偏离、风险概率和闭环状态生成，明确标记为“本地专家规则”。

## 视觉与交互

- 深色煤岩背景，橙色作为研究重点色，蓝色表示数据链路，红/黄/绿表示风险语义；不使用大面积渐变或装饰性圆球。
- 图表卡片保留清晰标题、单位、时间范围和数据来源。
- 所有 ECharts 实例使用现有初始化、ResizeObserver/resize 和 dispose 生命周期。
- 左侧导航在小屏变为横向滚动导航，图表矩阵单列堆叠，解释与建议保持可读。
- 生成建议过程中显示加载状态，失败时保留当前解释并显示回退来源。

## 验收标准

- 智库账号登录后可看到新大屏；企业端、监管端布局和行为不回归。
- 六类图表均有真实数据或明确空状态，不能出现随机占位数据。
- 未配置 DeepSeek 时可完整生成本地专家建议；配置后能显示 DeepSeek 来源。
- DeepSeek 请求失败时页面仍可生成本地建议。
- 建议内容包含等级、依据和时效，复制按钮可用。
- 桌面端和移动端无横向溢出；现有测试与新增 API/DOM 合约测试通过。
