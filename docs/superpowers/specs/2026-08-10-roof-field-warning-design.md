# 顶板灾变专业云图与预警联动设计

目标：把当前井下巷道从“有模型、有阶段按钮”提升为比赛视频可展示的顶板灾变数字孪生功能：云图可见、指标联动、风险弹窗清晰。

设计取舍：不引入外部大型仿真库，避免下载和工程复杂度；在 Three.js 内做工程表达，包括顶板应力场、位移场、综合风险场、网格、等值线、峰值标记和监测点标绘。数据采用监测点插值与阶段参数驱动，视频讲解时表述为“基于监测点的空间插值可视化”。

本轮范围：
1. 修正 roofFallWarning / emergencyResponse 阶段云图不可见问题，让云图覆盖顺槽顶板和工作面出口顶板。
2. 降低正常/关注阶段云图透明遮挡，危险阶段增强但不糊成一整片色膜。
3. 增加预警联动弹窗，显示阶段、风险等级、触发指标、处置建议。
4. 面板补充“IDW + Gaussian 插值”的专业说明，服务视频讲解。

不做：井上场景、三端完整页面、后端算法、真实有限元求解器。
