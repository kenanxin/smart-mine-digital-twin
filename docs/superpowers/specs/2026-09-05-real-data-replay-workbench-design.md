# 真实监测数据历史回放工作台设计

## 目标

在现有企业端数字孪生驾驶舱下方增加一个独立、全宽的数据回放工作台。工作台按老师提供的 CSV 原始记录推进，让七项监测指标、风险判定、模型结果、趋势图和 Three.js 场景使用同一条真实记录同步变化。

系统必须明确标注“历史数据回放”。不得把 CSV 回放描述为实时传感器采集，也不得为补足曲线生成模拟值。

## 数据边界

- 权威数据源为现有构建产物中的 20,000 条老师 CSV 记录。
- 回放顺序由原始时间、设备和稳定记录序号共同确定。
- 每个回放帧必须保留记录 ID、原始时间、设备、七项数值、数据质量、真实标签、预测标签、四级概率、置信度和标准化特征证据。
- 默认从当前重大风险代表记录所在位置开始，用户可跳转到任意索引或风险事件。
- 趋势窗口只包含真实相邻记录；窗口越过数据集首尾时截断，不循环伪造连接。

## 页面布局

现有三维驾驶舱保持第一屏主体验。在其下方增加全宽的回放工作台，形成以下层级：

1. 回放标题栏：数据源、总记录数、当前播放状态。
2. 摘要栏：当前序号、原始时间、综合风险、回放速度。
3. 主分析区：
   - 左侧为七项真实指标及 P05/P95 位置；
   - 中部为共享时间轴的 P95 指数趋势；
   - 右侧为当前窗口中的风险事件轨道。
4. 底部控制栏：上一条、播放/暂停、下一条、可拖动时间轴、速度选择和循环开关。
5. 追溯栏：记录 ID、设备、真实标签、预测标签和模型置信度。

桌面端采用三列分析区。移动端改为单列，顺序为控制与摘要、趋势图、指标、事件轨道，所有按钮和文字不得横向溢出。

## 回放状态机

前端维护唯一的回放控制器，状态包括：

- `idle`：已加载但未播放；
- `playing`：按选定速度推进；
- `paused`：停留在当前记录；
- `ended`：到达末条记录；
- `error`：接口或数据契约失败。

支持 `1x`、`2x` 和 `5x`。速度代表每个固定显示周期推进的记录数，不伪装成原始采样频率。拖动、上一条、下一条和事件跳转都会先暂停，再原子更新当前游标。

循环默认关闭。开启循环后，到达末条记录返回第 1 条，并在界面明确显示循环状态。

## API 设计

新增只读回放接口：

- `GET /api/roof-risk/replay/meta`：总数、字段结构、风险事件索引、默认游标和数据来源。
- `GET /api/roof-risk/replay/frame?index=N&window=48`：当前帧、前后边界和真实趋势窗口。

接口执行索引范围校验，并限制趋势窗口上限。响应沿用现有 `metrics`、`risk`、`model_output`、`feature_evidence` 和 `provenance` 契约，避免新旧界面产生两套指标语义。

回放接口不修改服务端选中事件或闭环进度，因此多个用户同时观看不会互相改变页面。企业端、监管端和专家端可以独立读取同一记录，但本次只在企业端开放完整回放控制。

## 同步渲染

一次游标变化只产生一次帧请求。响应成功后按同一批次更新：

- 回放摘要、追溯信息和七项指标；
- P95 趋势 ECharts 实例；
- 风险分、风险等级和 XGBoost 解释；
- Three.js 指标状态、风险场和告警卡。

图表复用现有 ECharts 实例和 `ResizeObserver`，数据更新使用 `setOption`，不重复初始化。播放期间若上一次请求未完成，则不叠加新请求，避免旧响应覆盖新游标。

## 异常处理

- 接口失败：自动暂停，保留最后一帧并显示“回放中断”和错误原因。
- 索引越界：界面回到有效边界，不显示空数据。
- 单项数值缺失：该指标显示“缺失”，其余真实字段继续渲染。
- 模型字段缺失：保留监测回放，但模型区域显示不可用，不推断或补造概率。
- Three.js 尚未完成加载：数据回放继续，场景在可用后同步到当前帧。

## 视觉原则

- 用青色表达正常数据流、黄色表达接近 P95、红色表达超过阈值或重大风险。
- 趋势图是回放工作台的视觉主体，真实指标卡和风险事件围绕它组织。
- 动画仅用于播放游标、最新数据点和状态切换，不使用无意义装饰。
- 所有时间均显示 CSV 原始时间；系统当前时间不得与数据时间混淆。
- 数据源名称、记录 ID 和哈希保持可见，便于教师审查真实性。

## 验收标准

- 20,000 条记录均可通过合法索引读取，首尾边界正确。
- 播放、暂停、前后步进、拖动、三档速度、循环和事件跳转行为一致。
- 每个游标位置的指标、风险、模型、图表和 Three.js 使用同一记录 ID。
- 播放过程不生成随机或模拟监测值。
- ECharts 不重复初始化，调整布局后能正确缩放，无空白画布。
- 桌面与 390px 移动视口无横向溢出或文本重叠。
- 原有三端权限、闭环操作和真实数据预检全部继续通过。
