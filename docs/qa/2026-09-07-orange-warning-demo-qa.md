# 橙色预警三端协同演示 QA

## 验收范围

- 企业端：真实记录触发橙色预警、确认预警、填写补强支护措施与工单、上传现场照片、整改复提。
- 监管端：查看工单、照片与后续监测真实对照，先驳回整改，再核验通过。
- 智库端：查看模型概率与主要因素、检索 3 条真实相似案例、填写复盘结论并归档。
- 跨端状态：同一台电脑依次切换账号，业务状态和图片证据持续可见。
- 页面稳定性：检查监管端和智库端板块重叠、横向溢出、意外控制台错误，以及企业处置期间 Three.js 相机跳变。

## 数据口径

- 触发记录：`REC-202511101149-02909`，较大风险，综合风险分 70，模型置信度 99.98%。
- 后续真实对照：`REC-202511101153-02911`，一般风险，综合风险分 45，时间晚 4 分钟。
- 后续记录只用于真实监测对照，不作为整改导致风险下降的因果证据。
- 相似案例由老师数据的 7 项标准化特征距离排序产生，不使用虚构案例。
- 数据源 SHA-256：`86D4C2FB192721B2745F00076AEB00CF351C654ED936DDB098BFA6217E30AC6A`。

## Chrome 自动化流程

运行环境：Google Chrome，1366 x 768，设备像素比 1，本地服务 `http://127.0.0.1:8094`。

1. 企业端启动演示并确认弹窗展示真实记录编号、风险分和置信度。
2. 上传 1 张 JPEG 现场照片，提交工单与处置措施。
3. 监管端读取同一照片和工单，填写意见与期限后驳回。
4. 企业端读取驳回原因，补充措施并第 2 次提交。
5. 监管端核验通过。
6. 智库端读取 3 条真实相似案例，确认闭环并归档。

最终状态：`archived`；状态修订次数 7；时间线事件 7 条；提交次数 2；照片 1 张；监管结论 `approved`。
