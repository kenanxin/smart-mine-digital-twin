## 自动化验证

- 服务状态机：高风险六节点、低风险结束、资源不足、反思返回。
- API：会话认证、输入校验、XGBoost血缘、节点顺序与dry-run边界。

- 全量回归：执行 `npm test`。
- 离线预检：执行 `npm run preflight:offline`。

## 人工验证路径

1. 使用智库端账号登录。
2. 在科研分析大屏导航点击“智能体研判”。
3. 确认顶部显示“六智能体后端已就绪 · XGBoost适配器”。
4. 点击“运行六智能体研判”。
5. 确认节点顺序为A1、A2、A3、A5、A4、A6。
6. 确认A4显示“待人工确认”，详情包含 `dry-run` 安全边界。
7. 逐个点击节点，核对输入证据和服务器输出摘要。

## 演示口径

平台先由真实数据和XGBoost触发算法预警，再由六智能体完成知识检索、方案形成、资源校验、协同草案与反思检查点，最终由企业、监管和专家三类人员完成实际处置闭环。六智能体不是三个登录角色；规则辅助研判不等于生产级自动控制。
